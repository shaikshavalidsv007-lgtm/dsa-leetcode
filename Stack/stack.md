Stack patterns

1) Monotonic Stack - ascending and descending
2) Evaluate Expression - Bodmas
3) Stack undo operation - keep removing adjacent elements as per the question
4) Paranthesis pattern - match paranthesis
5) Stack based design - design a new data structure
6) Recursive stack - manipulate the stack without using any extra space or extra data structure



Interview insight:
If a problem involves:
reversing order
last seen element
nearest greater or smaller element
matching brackets
Stack should immediately come to mind.



Classic patterns — the eight most common stack patterns in coding interviews:

Balanced brackets — the archetypal stack problem
Next greater element / daily temperatures — the monotonic stack family
Min stack — augmenting a stack with extra state
Expression evaluation — the two-stack trick
Iterative DFS — replacing the call stack explicitly
Largest rectangle in histogram — hard monotonic stack application
Decode string — nested structure unwinding
